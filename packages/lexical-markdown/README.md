This is a fork of `@lexical/markdown` that fixes
https://github.com/facebook/lexical/issues/7575.

Installation:

```
npm install @reinseth/lexical-markdown
```

If you also use `@lexical/react`, which depends on `@lexical/markdown`,
then you should also use the fork of that:

```
npm install @reinseth/lexical-react
```

This fork will live as long as the PR is open:
https://github.com/facebook/lexical/pull/7979
